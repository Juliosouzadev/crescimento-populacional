# Crescimento Populacional — Censo 2010 x 2022

Dashboard Streamlit para a persona 3 (prefeitos de Curitiba, Porto Alegre, BH, Salvador e Florianópolis).

## Rodar local
    pip install -r requirements.txt
    streamlit run app.py

## Deploy
1. Crie um repositório no GitHub e envie esta pasta inteira (app.py, requirements.txt, dados/, imagens/).
2. Em share.streamlit.io: Create app -> repositório -> branch `main` -> Main file path `app.py` -> Deploy.

Fonte: IBGE, Censo Demográfico 2022 — População 2010 compatibilizada (5.570 municípios).
